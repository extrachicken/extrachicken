# Игра жизни Конвея

Реализация на Python «Игры жизни» Конвея, клеточного автомата, разработанного британским математиком Джоном Конвеем в 1970 году.

## Обзор

«Игра жизни» Конвея — это игра с нулевым количеством игроков, которая симулирует клеточные автоматы. Игра развивается на основе своего начального состояния без дальнейшего ввода. Клетки живут или умирают по простым правилам:

1. Любая живая клетка с менее чем двумя живыми соседями умирает (недонаселение)
2. Любая живая клетка с двумя или тремя живыми соседями продолжает жить
3. Любая живая клетка с более чем тремя живыми соседями умирает (перенаселение)
4. Любая мертвая клетка с ровно тремя живыми соседями оживает (размножение)

## Особенности

- Консольная и графическая визуализация
- Предопределенные паттерны (глайдер, мигалка, маяк, пульсар)
- Случайная инициализация
- Интерактивный графический интерфейс с управлением мышью и клавиатурой
- Настраиваемый размер сетки и скорость симуляции

## Требования

- Python 3.6+
- Pygame (для версии с графическим интерфейсом)
`pip install pygame`

## Использование

### 1. Консольная версия

Запустить с помощью команды:

`python game_of_life.py`

Опциональные аргументы:
- `--width`: Ширина сетки (по умолчанию: 50)
- `--height`: Высота сетки (по умолчанию: 20)
- `--generations`: Количество поколений для симуляции (по умолчанию: 100)
- `--delay`: Задержка между поколениями в секундах (по умолчанию: 0.1)
- `--pattern`: Начальный паттерн (варианты: glider, blinker, beacon, pulsar)
- `--random`: Инициализировать случайными состояниями клеток

Пример:

`python game_of_life.py --width 80 --height 40 --pattern glider --generations 200`

### 2. Графическая версия

Запустите графическую версию с помощью:

`python game_of_life_gui.py`

Эта версия открывает окно и отображает более визуальное представление с кликабельными клетками.


Вы можете настроить с помощью аналогичных параметров:

`python game_of_life_gui.py --width 80 --height 50 --pattern pulsar`


В графическом интерфейсе:
- **Кликайте** на клетки, чтобы сделать их живыми/мертвыми
- Нажмите **Пробел**, чтобы запустить/приостановить симуляцию
- Нажмите **R**, чтобы сбросить со случайными клетками
- Нажмите **C**, чтобы полностью очистить сетку
- Нажмите стрелки **Вверх/Вниз**, чтобы настроить скорость симуляции
- Закройте окно для выхода

## Создание своих собственных паттернов

С помощью графической версии вы можете:
1. Начать с чистой сетки (опция `--pattern` или нажмите **C**)
2. Кликать на клетки, чтобы создать свой собственный паттерн
3. Нажать Пробел, чтобы увидеть, как ваш паттерн эволюционирует

## Понимание того, что вы видите

- Белые квадраты (графический интерфейс) или символы ■ (консоль) — живые клетки
- Черные квадраты (графический интерфейс) или символы □ (консоль) — мертвые клетки
- Каждое обновление представляет одно «поколение», где все клетки обновляются одновременно
- Счетчик показывает, какое поколение вы сейчас просматриваете
