# Как пользоваться:
1. В папку со скриптом кидаем ваш сценарий
2. В скрипте вводим ваш ключ API от Elevenlabs
3. В character_setting по шаблону вписываем настройки для каждого персонажа
4. В консоли пишем `python3 script.py *имя файла.txt*`
5. Вывод будет в той же папке, каждая фраза будет в отдельном файле, все файлы будут распределены в соответсвующие папки по персонажам (создаются сами)
